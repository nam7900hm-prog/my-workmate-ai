# my workmate ai v4

Excel과 Word 사용이 익숙하지 않아도 자료나 양식을 고르고 원하는 일을 글이나 말로 설명하면 작업계획을 먼저 보여주고 승인 후 결과 사본을 만드는 개인용 업무비서입니다.

## 기본 작업 흐름

`선택 → 설명 → AI 질문 → 계획 확인 → 실행·검증 → 결과 확인`

작업 화면에는 단계 탭을 나열하지 않고 아래의 `← 이전`과 `다음 →`만 표시합니다. 사용자는 내 자료와 내 양식과 최근 작업 및 보관함 중 어느 곳에서든 작업을 시작할 수 있습니다.

## 현재 실제 구현된 기능

- `.xlsx` `.xls` `.csv`의 모든 시트 분석
- 시트와 사용 범위 및 행·열과 표 영역과 제목 후보 분석
- 날짜와 숫자와 문자와 수식 및 반복값과 서식 셀 분석
- 공통 머리글과 시트 참조 수식을 이용한 자료 관계 확인
- `.docx` `.pdf` `.pptx` `.txt` `.hwpx`의 본문 추출
- `.hwp`는 등록 상태와 PDF 변환 필요 여부를 표시하고 한글 2018로 변환한 PDF를 분석
- 변환 문서 묶음의 `전체문서_분석색인.json`을 내 자료에서 가져와 키워드 드롭다운과 직접 입력으로 검색
- 개인 문서 색인은 배포 파일에 포함하지 않고 현재 브라우저의 대용량 저장소에만 보관
- 글자가 없는 스캔 PDF를 승인 후 OpenAI 파일 입력으로 분석하고 학생별 이름과 실제 작성 내용 분리
- `.jpg` `.jpeg` `.png` `.webp` 사진의 OpenAI API 문자·표 분석
- 노트북·휴대폰의 `.flac` `.mp3` `.mp4` `.mpeg` `.mpga` `.m4a` `.ogg` `.wav` `.webm` 회의 녹음 음성변환
- Chrome·Edge의 바로 받아쓰기와 단계적 자동 재시작
- 말 사이에 오래 쉬어도 계속 저장되는 MediaRecorder 긴 녹음과 녹음 파일 자동 선택
- 여러 자료 선택 및 자료 없이 글·말로 시작
- 최근 완료 작업을 덮어쓰지 않고 `지난번처럼 새로 시작`으로 복사
- OpenAI API를 통한 요청 확인과 추가 질문 및 작업계획 생성
- 승인한 계획을 바탕으로 표 또는 글 결과 생성과 검증 표시
- 회의 녹취를 회의 개요·참석자·안건별 논의·결정사항·후속 할 일·확인 필요로 나누어 회의록 작성
- 녹취에 없는 참석자·담당자·기한을 만들지 않고 발언자가 불명확하면 확인 필요로 표시
- 계획 확인 단계에서 Excel·Word·PDF·PowerPoint·텍스트·CSV 결과 형식 선택
- Excel 결과를 원본 통합문서 사본 또는 선택한 Excel 양식에 반영
- Word 양식을 선택하면 원본 양식 구조를 보존하고 생성 결과를 뒤에 추가
- 같은 머리글이 있으면 해당 열 아래에 작성하고 없으면 `AI 결과` 시트 추가
- 승인된 Excel 명령으로 지정 범위의 값 교체와 셀 입력 및 수식 입력 실행
- 일치 셀 배경색과 실제 조건부서식을 결과 파일에 보존
- 학생 자료에서 최대 200명 추출
- `세특·세부능력 및 특기사항`과 `행발·행동특성 및 종합의견` 요청 자동 구분
- 세특은 교과 성취과정과 수업 참여 및 변화 중심이고 행발은 지속적인 생활 관찰 중심으로 별도 작성
- 2026학년도 학교생활기록부 기재요령과 사용자 제공 PDF 128~150쪽 작성 분석 및 사용자와 합의한 문장 기준을 함께 적용
- 교사 관찰과 활동 내용 및 학생 소감에는 고정 우선순위를 두지 않고 실제 입력 내용과 구체성에 따라 반영
- 생기부 문안은 마지막뿐 아니라 중간의 모든 완결 문장을 명사형 음슴체로 끝내며 서술형 종결을 자동검사
- 20명씩 안전하게 나누어 입력 자료에 고정 우선순위를 두지 않은 1안·2안·3안 생성
- 20명 단위 처리 중 일시적인 실패가 발생하면 각 묶음을 최대 3회 재시도
- 앞 묶음의 표현을 다음 묶음에서 피하도록 전달하고 응답 인원 수도 확인
- 1안은 확인된 사실 중심이고 2안은 관찰 가능성 유추 부분을 별도 표시
- 쉼표 금지와 마침표 확인 및 200명 전체 문장 유사도 검사
- 학생별 세 안 선택·교사 수정·전체 승인 후 선택한 형식으로 다운로드
- Excel 결과 화면에서 실제 작업 설명과 함수식 및 Excel·Google Sheets 왕초보 따라하기 제공
- Excel 드롭다운 데이터 유효성 검사 명령과 숨겨진 선택 목록 시트 생성
- Excel 정렬과 필터 및 중복제거와 행·열 전환 명령
- 정렬·중복제거 대상에 수식이 들어 있으면 상대참조 손상을 막기 위해 자동 실행하지 않고 원본을 보존
- 브라우저 자동저장과 최근 자동백업 4개 및 중요 백업
- ZIP 백업 내보내기와 가져오기 및 복원 미리보기와 승인 복원
- 큰 원본 파일을 브라우저 대용량 저장소에 보관하고 ZIP 백업에 포함
- 자료와 양식 삭제 후 보관함 복원
- 작업계획 전송 전에 이름과 전화번호와 주민등록번호 및 이메일 가림
- 학생명뿐 아니라 성명·직원명·교사명·담당자·작성자 열의 이름도 찾아 가림
- 사진과 음성 및 스캔 PDF 원본 전송이 필요한 경우 별도 경고
- OpenAI 응답 저장을 요청하지 않는 `store: false` 설정
- Excel 수식은 외부 주소·외부 파일·웹 호출을 포함하면 실행하지 않음
- 설정 화면에서 `연결 전` 또는 `사용 준비됨` 상태 확인
- Google 계정을 읽기 전용으로 연결해 내 Google Sheets 목록 표시
- 여러 Google Sheets를 선택하고 `.xlsx` 사본으로 내 자료에 가져오기
- 가져온 Google Sheets의 모든 시트를 기존 Excel 분석 과정으로 분석
- Google 연결 해제와 서버 암호화 쿠키 보관

## OpenAI API 승인 방식

사용자가 `다음 →`을 눌러 AI 분석 단계에 도착하면 안내창이 표시됩니다. `확인`을 누르기 전에는 자료를 API로 보내지 않습니다.

- 일반 글과 추출 문서: 확인된 개인정보를 가린 뒤 필요한 내용만 전송
- 사진과 음성 및 스캔 PDF: 원본을 분석해야 하므로 별도 경고 후 전송
- API 키: 브라우저에 넣지 않고 Vercel 서버 환경변수에만 저장
- API 키가 없으면 로컬 파일 분석과 저장 및 백업은 가능하지만 AI 계획과 결과 생성은 중단

## 환경변수

로컬에서는 `.env.local`을 만들고 Vercel에서는 Project Settings의 Environment Variables에 같은 값을 등록합니다.

```env
OPENAI_API_KEY=
OPENAI_MODEL=gpt-5-mini
OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
GOOGLE_TOKEN_SECRET=
GOOGLE_REDIRECT_URI=https://my-workmate-ai.vercel.app/api/google/callback
```

OpenAI API 요금은 ChatGPT 구독과 별도이며 실제 사용량에 따라 API 계정 잔액에서 차감됩니다.

## Google Sheets 연결 설정

Google Sheets 연결은 개인 사용 기준의 읽기 전용 기능입니다. 원본 시트는 수정하지 않고 선택한 문서를 Excel 사본으로 가져옵니다.

1. Google Cloud Console에서 프로젝트를 만듭니다.
2. `Google Drive API`를 사용 설정합니다.
3. Google Auth Platform에서 앱 이름과 사용자 지원 이메일을 입력합니다.
4. 앱을 테스트 상태로 두고 본인의 Google 계정을 테스트 사용자로 추가합니다.
5. OAuth 클라이언트에서 `웹 애플리케이션`을 선택합니다.
6. 승인된 리디렉션 URI에 `https://내-버셀-주소.vercel.app/api/google/callback`을 등록합니다.
7. Vercel 환경변수에 `GOOGLE_CLIENT_ID`와 `GOOGLE_CLIENT_SECRET`을 등록합니다.
8. `GOOGLE_TOKEN_SECRET`에는 임의의 32자 이상 비밀 문자열을 등록합니다.
9. `GOOGLE_REDIRECT_URI`에는 `https://my-workmate-ai.vercel.app/api/google/callback`을 등록합니다.
10. 환경변수 저장 후 Vercel에서 다시 배포합니다.

로컬 시험용 리디렉션 URI는 `http://localhost:3000/api/google/callback`입니다. Google 접근 토큰은 브라우저 JavaScript나 로컬 저장소에 노출하지 않고 서버의 암호화된 HttpOnly 쿠키에만 보관합니다. 연결을 해제하면 해당 쿠키를 삭제합니다.

## 저장과 휴대폰 연동

현재 버전은 한 사람이 한 컴퓨터와 브라우저에서 사용하는 로컬 저장 방식입니다. 로그인과 Supabase 및 PC·휴대폰 동기화 문구는 화면에서 제거했습니다. 다른 기기로 옮길 때는 설정의 `백업하기`와 `백업 가져오기`를 사용합니다.

개인 HWP/HWPX 변환 자료의 정리표는 `내 자료 → 내 문서 정리표 가져오기`에서 변환 ZIP 안의 `전체문서_분석색인.json`을 선택합니다. 이 색인은 Vercel이나 GitHub에 포함되지 않으며 사용 중인 브라우저에만 저장됩니다.

나중에 실시간 PC·휴대폰 연동이 필요하면 Supabase 인증과 사용자별 데이터베이스 및 저장소와 접근정책을 별도 단계로 연결해야 합니다. 현재 버전이 클라우드 동기화된다고 표시하지 않습니다.

## 정확한 제한사항

- 오래된 `.doc`와 `.ppt`는 직접 분석하지 않으므로 `.docx`와 `.pptx`로 저장해야 합니다.
- 글자가 없는 스캔 PDF는 승인 후 OpenAI API 파일 분석이 필요하며 판독이 어려운 손글씨는 `[판독 불가]`로 표시될 수 있습니다.
- PDF 내 양식은 보이는 구조를 참고해 새 Excel·Word·PDF 결과로 만들며 PDF 원본 칸에 직접 입력하는 기능은 아직 없습니다.
- PDF는 한글 표시 안정성을 위해 페이지 내용을 이미지로 넣으므로 글자 검색과 복사 기능이 제한됩니다.
- 바로 받아쓰기는 운영체제와 브라우저 음성서비스 상태에 따라 잠시 멈출 수 있으며 앱은 자동 재시작합니다. 중요한 장시간 발언은 `긴 녹음`을 사용하면 쉬는 구간에도 파일 녹음이 계속되고 완료 후 내 자료에 자동 선택됩니다.
- 한 파일은 20MB 이하만 음성변환합니다. 매우 긴 휴대폰 녹음은 여러 파일로 나누거나 낮은 음질로 내보내야 합니다.
- 현재 음성변환은 누가 말했는지 항상 정확히 구분하는 화자 분리 기능을 보장하지 않습니다. 불명확한 발언자는 회의록에서 확인 필요로 남깁니다.
- OpenAI API의 실제 계획 품질과 결과 정확도 및 200명 전체 생성은 API 키 연결 뒤 최종 검증해야 합니다.
- 자동 개인정보 탐지는 정규식과 선택 자료의 학생 이름을 기준으로 하며 사진·음성·스캔 PDF 안의 개인정보를 전송 전에 완전히 가릴 수는 없습니다.
- Supabase 실시간 동기화는 현재 구현하지 않았습니다.
- Google Sheets는 최대 100개까지 최근 수정 순으로 표시합니다. 공유 드라이브와 매우 큰 시트 및 Google 권한 정책에 따른 접근 제한은 실제 계정 연결 후 확인해야 합니다.

## 검증 결과

- 일반 회사 Excel 구조·추출·교체·함수·색상·조건부서식 검사 통과
- Word·PDF·PowerPoint·TXT·HWPX 입력과 결과 파일 재열기 검사 통과
- 개인정보 가림과 자동백업 4개 및 ZIP 원본 복원 검사 통과
- 요금이 발생하지 않는 가상 OpenAI 서버로 계획·실행·사진·음성·200명 세 초안의 전체 API 왕복 검사 통과
- npm 잠금파일을 새 폴더에서 설치한 뒤 Vercel용 production build 통과
- SheetJS는 공개 npm의 오래된 0.18.5 대신 공식 배포본 0.20.3으로 교체하고 PostCSS·Sharp·UUID 보안 버전을 고정
- 실제 OpenAI 모델의 표현 품질과 비용은 사용자의 API 키 연결 뒤 실제 자료로 확인해야 함

`pptxgenjs`의 최신 공개 버전에는 내부 이미지 크기 판독 모듈의 서비스 거부 보안 경고가 남아 있습니다. 앱은 해당 위험 형식인 ICNS·JXL·HEIF 파일을 입력 형식으로 받지 않으며 일반 PPTX 결과 생성만 사용합니다. 공식 수정 버전이 공개되면 즉시 올려야 합니다.

## GitHub와 Vercel 배포

1. 최종 승인된 ZIP의 내용만 빈 GitHub 저장소 루트에 올립니다.
2. GitHub 루트에 `app` `lib` `public` `package.json`이 직접 보여야 합니다.
3. Vercel Framework Preset은 Next.js로 설정합니다.
4. Root Directory는 `./`로 둡니다.
5. `vercel.json`이 설치 명령을 `npm ci`로 고정합니다.
6. Vercel 환경변수에 OpenAI 설정을 등록한 뒤 새로 배포합니다.
7. 과거 버전 파일과 v4 파일을 같은 저장소에서 섞지 않습니다. 특히 예전 `pnpm-lock.yaml`은 삭제합니다.

저장 키와 백업 형식은 v4로 분리되어 과거 배포본과 충돌하지 않습니다.
