# AI Personal Assistant v2

Excel과 Word를 잘 몰라도 자료 또는 양식을 선택하고 원하는 결과를 글이나 음성으로 설명하여 작업계획을 확인하는 개인용 업무비서 신버전입니다.

## 실제 구현된 기능

- 신버전 독립 화면과 `홈 / 사용설명 / 내 자료 / 진행 중 작업 / 내 양식 / 최근 작업 / 보관함 / 설정` 탭
- `1 선택 → 2 설명 → 3 AI 질문 → 4 계획 확인 → 5 실행·검증 → 6 결과 확인` 작업 흐름
- 브라우저와 휴대폰 뒤로가기 및 화면 하단 `← 이전 / 다음 →`
- 여러 자료 업로드와 보관 및 복수 선택
- 자료 없이 글·말로 시작
- 잠시 침묵해 브라우저 음성인식이 종료되면 자동 재시작하는 연속 받아쓰기
- 사용자가 `받아쓰기 완료`를 누를 때까지 확정 문장 누적
- 개인 양식 등록과 양식에서 작업 시작
- 진행 중 작업 자동저장 및 최근 작업·보관함 구조
- 설정 안의 `백업하기 / 백업 가져오기`와 복원 미리보기
- OpenAI API 설정 시 자료 목록과 요청을 바탕으로 AI 질문과 작업계획 생성

## 정확한 제한사항

현재 버전은 새 앱의 화면과 작업 흐름을 검증하는 기반입니다. Word·PDF·사진·음성파일의 본문 분석과 범용 Excel·Word 결과 생성 엔진은 아직 연결되지 않았습니다. OpenAI 키가 없으면 AI 의논은 안내용 계획만 표시하며 실행 버튼은 활성화하지 않습니다. 지원하지 않는 작업을 완료했다고 표시하지 않습니다.

브라우저 음성인식은 Chrome·Edge에서 가장 잘 작동하지만 운영체제와 브라우저 정책에 따라 세션이 중단될 수 있습니다. 앱은 중단 시 자동 재시작을 시도합니다. 긴 상담과 회의는 향후 녹음파일을 서버 음성변환 엔진으로 처리하는 것이 안전합니다.

업로드 자료는 브라우저 저장용량을 고려해 2.5MB 이하만 ZIP 백업에 원문을 포함합니다. 큰 파일은 목록 정보만 보관됩니다. 학생 생활기록부 같은 민감자료를 실제 서비스에서 처리하려면 별도 보안 설계와 데이터 보존정책이 필요합니다.

## 실행

```bash
pnpm install
pnpm dev
```

## 선택적 AI 설정

`.env.local`:

```env
OPENAI_API_KEY=서버용_API_키
OPENAI_MODEL=gpt-5-mini
```

API 키는 브라우저 코드에 넣지 말고 Vercel 환경변수에만 저장합니다.

## GitHub와 Vercel

1. ZIP을 빈 GitHub 저장소의 루트에 압축 구조 그대로 올립니다.
2. 루트에 `app`, `lib`, `public`, `package.json`이 보여야 합니다.
3. Vercel에서 Framework Preset은 Next.js로 설정합니다.
4. Root Directory는 `./`로 둡니다.
5. AI 기능을 사용할 때만 Vercel 환경변수에 OpenAI 키를 등록합니다.

이 ZIP은 기존 배포본을 덮어쓰는 수정본이 아니라 빈 저장소에 올리는 신버전입니다. 과거 파일과 섞지 마세요.
